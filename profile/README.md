**WRAITH** is a confidential federated-learning network for robots. A deployed robot is the most invasive sensor ever placed in a home, hospital, or factory. WRAITH lets a fleet learn collectively **without any robot's raw video, audio, or sensor data ever leaving its hardware** — robots train locally and contribute only *encrypted model updates*. The result is a community-owned physical-AI model that gets smarter with every environment, owned by no single company.

> **Raw frames ever uploaded: 0.** Privacy by architecture, not by policy.

### A role for everyone — with or without a robot

- 🤖 **Robot owners** — enroll a robot, train locally, earn WRTH for verified contributions
- 🛡️ **Validators** — stake WRTH and review contributions for tampering; earn fees
- 🧩 **Aggregators** — run secure-aggregation enclave nodes, earn round fees
- 🪙 **Stakers** — secure the network and share protocol revenue
- 🏪 **Model consumers** — license the shared skill-models for your robots or products
